# Relatório — 1ª Entrega (MVP)

## 1. Nome do projeto
Lista Fácil

## 2. Problema e público-alvo
O projeto busca facilitar a organização de tarefas do dia a dia. O público-alvo são pessoas que precisam registrar atividades e acompanhar o que já foi concluído.

## 3. Solução e funcionalidades
O sistema oferece cadastro, edição, conclusão e exclusão de tarefas, além de filtros por situação e prioridade. Os dados são mantidos no navegador usando LocalStorage.

## 4. Escopo do MVP
O MVP contém todas as funcionalidades essenciais para demonstrar a solução: criar tarefa, visualizar, editar, concluir, excluir e filtrar.

## 5. Tecnologias
HTML5, CSS3 e JavaScript, utilizando LocalStorage para persistência local.

## 6. Viabilidade
A solução é viável porque utiliza tecnologias leves, gratuitas e executadas diretamente no navegador, sem necessidade de servidor ou banco de dados para o MVP.

## 7. Riscos
- Perda dos dados se o armazenamento local do navegador for apagado.
- O MVP não possui sincronização entre dispositivos.
- A ausência de servidor limita recursos multiusuário.

## 8. Como executar
Abrir o arquivo `index.html` em um navegador moderno.

## 9. Evolução futura
Como produto final, podem ser adicionadas categorias, prazos, autenticação, banco de dados e sincronização online.
