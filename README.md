# Lista Fácil

Sistema simples de organização de tarefas desenvolvido para a disciplina de Fábrica de Software.

## Problema
Pessoas podem ter dificuldade para organizar tarefas e acompanhar o que já foi concluído.

## Solução
O Lista Fácil permite cadastrar, editar, concluir, excluir e filtrar tarefas, com prioridade e persistência local no navegador.

## MVP
- Adicionar tarefa
- Definir prioridade
- Listar tarefas
- Marcar como concluída
- Editar tarefa
- Excluir tarefa
- Filtrar tarefas
- Salvar dados no localStorage

## Tecnologias
- HTML5
- CSS3
- JavaScript
- LocalStorage do navegador

## Como executar
1. Extraia a pasta do projeto.
2. Abra o arquivo `index.html` em um navegador.
3. Não é necessário instalar dependências nem configurar servidor.

## Demonstração sugerida
1. Adicionar uma tarefa de prioridade alta.
2. Adicionar outra tarefa.
3. Marcar uma como concluída.
4. Usar o filtro "Concluídas".
5. Editar uma tarefa.
6. Excluir uma tarefa.
7. Atualizar a página e mostrar que as tarefas continuam salvas.
